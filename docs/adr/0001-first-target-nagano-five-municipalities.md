# ADR 0001: 最初の対象は長野県の 5 市（東御・佐久・飯山・大町・伊那）

- ステータス: 採用（2026-09-10、事業側の承認済み）

## 背景
縦断パイプラインを最小で動かすため、1 都道府県に絞り、掲載ページが静的 HTML で robots.txt に阻害されない自治体を選ぶ。

## 決定
- 都道府県: 長野県（移住需要が高く、市町村数が全国最多で横断検索の価値が出やすい）
- 自治体: 東御市（市ドメイン直下の空き家バンクサイト）、佐久市（市の移住情報サイト）、飯山市（市の移住定住支援サイト）、大町市（市の移住情報総合サイト）、伊那市（公式サイト）
- 掲載先が公式ドメイン外でも、自治体または自治体の移住推進組織が運営主体と明記されている場合は巡回対象。根拠の引用と URL を `data/sources/nagano.yaml` に残す
- アットホーム空き家バンク、LIFULL HOME'S、楽園信州などのプラットフォームは巡回せずリンクのみ

## 影響
- 自治体を増やすときは同じ基準（運営主体の明記、静的 HTML、robots）で yaml に追記する
