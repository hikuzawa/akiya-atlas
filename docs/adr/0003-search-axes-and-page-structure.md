# ADR 0003: 検索軸とページ構成

- ステータス: 採用（2026-09-10）

## 決定
- 検索軸は 都道府県 × 市町村 × 価格帯 × 移住・改修補助金の有無。静的 JSON 索引 `search/index.json` をクライアント側 JS で絞り込む
- 価格帯: 100 万円未満 / 100〜300 万円 / 300〜500 万円 / 500〜1,000 万円 / 1,000 万円以上 / 賃貸 / 価格記載なし・応相談
- 補助金の有無は市町村単位の属性（移住支援・改修補助・解体補助・家財処分補助）。`sources.yaml` に出典 URL と取得日付きで持つ
- ページ: `/`、`/nagano/`、`/nagano/<slug>/`、`/nagano/<slug>/<listing_no>/`、`/owners/`、`/about/`、`/data/`
- 物件ページは要約・数値・地図・一次情報リンク・取得日時のみ。写真と本文は載せない
- 基準 URL は `site.toml` の `base_url`（仮: https://akiya-atlas.pages.dev、後に akiya-atlas.com）

## 影響
- 市町村の slug は JIS コードとローマ字名（例 `20219-tomi`）で衝突を避ける
