# ADR 0005: 視覚要素の優先順位と生成画像の扱い

- ステータス: 採用（2026-09-10）

## 決定
優先順に:
1. 地図埋め込み（Google Maps Embed API の place モード。市町村ページは市町村名、物件ページは所在地文字列で検索）と Street View（緯度経度が得られる場合のみ。当面は未使用）
2. コード生成の SVG 図解: 市町村別の掲載件数、価格分布、築年分布、査定・解体の手続きフロー
3. 自治体・観光協会の公式 YouTube / Instagram / X の埋め込み（埋め込み機能経由のみ。今フェーズは未実装）
4. ライセンス判定を通過した写真（今フェーズは未実装）。物件写真は原則除外

- 実在の物件・場所を AI 画像生成で描かない。生成画像は説明図・ピクトグラムに限り「AI 生成のイメージ図」と明記する
- 図解には「自動生成」の注記を付ける。データ点が 3 未満のグラフは出さず、その旨を書く
- 埋め込み・画像の利用元・ライセンス・取得日・クレジットはデータとして保持し、`/data/` に一覧する

## 影響
- Maps のキーが無い環境では地図は外部リンクにフォールバックし、ビルドは失敗しない
