# ADR 0012: 地域限定の広告案件は都道府県ごとの所有者向けページで出し分ける

- ステータス: 採用（2026-09-14）。設計のとおり実装した（末尾の追記）
- 関連: ADR 0010（掲載枠・規約の検査・クリックの計測）、sitemill ADR 0019・0021（案件の選定と保留）

## 背景

案件の選定は、対応地域がサイトの対象地域と重ならない案件を除外せず保留にする（sitemill ADR 0021）。
`data/affiliates/profile.yaml` の対応地域を `[全国]` にしたので、首都圏限定・関西限定といった案件は
これから保留に溜まる。溜めるだけでは使えないので、出し分け方を先に決めておく。

制約が 1 つある。ADR 0010 は**物件ページ・市町村ページ・トップに広告を置かない**と決めた。
読み手が購入・入居を検討する人で、所有者向けの広告は文脈が合わないためで、この判断は変えない。
地域限定の案件を出すには、**所有者だと分かっている読み手に、地域の文脈で会える場所**が要る。

## 決定（案）

### 1. 置き場所は都道府県ごとの所有者向けページ `/owners/<pref>/`

市町村ページには置かない。読み手が自分で「所有者の方へ」を選んだページにだけ置く。

- 市町村ページと物件ページの「この地域に空き家をお持ちの方へ」の行き先を、`/owners/` から
  その県の `/owners/<pref>/` に変える
- 中身は全国版の焼き直しにしない。県内の補助制度の一覧、県内の市町村の窓口、県内の掲載件数を載せる
- 枠は「相談先」1 つ（`owners-pref-consult`）から始める。流れの図の直後の枠は後から足せる

**理由**: 47 ページなら A8 の掲載 URL の届け出（ADR 0010 の `akiya-atlas ad-urls`）に収まる。
1,740 ページは届け出も `ad_check.py` の検査も現実的でない。

### 2. 案件は対応地域を都道府県で持つ

`Offer` に 2 つ足す。

```python
regions: tuple[str, ...] = ()  # 対応する都道府県名。空なら全国対応
region_quote: str = ""         # 対応エリアの原文（選定結果の region_quotes から取る）
```

- 値は 47 都道府県名のいずれか。「首都圏」「関東一円」のような語は**登録のときに人が都道府県へ
  展開する**。原文は `region_quote` に残す。推定で広げない（ADR 0004 の quote-then-parse と同じ扱い）
- `regions` が空なら全国対応。いま登録済みの案件は何も書かなくてよい

### 3. 出し分けの規則（同じ枠の同じ種別の中で）

上から順に見て、最初に見つかった 1 社だけを出す。

1. そのページの都道府県を `regions` に含む案件
2. 全国対応の案件（`regions` が空）
3. どちらも無ければ**その種別は枠ごと出さない**（「準備中」も出さない。`/owners/` の相談先一覧は
   種別の全体像を見せる場所なので準備中を出すが、県のページは出せるものだけを出す）

同じ段に複数あれば `rank` の小さい方。地域限定を全国より先に見るのは、その地域の事業者に直結する
方が成果になりやすいため。全国案件の方が明らかに良ければ `rank` を手で下げて上書きする
（ADR 0010 の四半期の見直しと同じ運用）。

### 4. 「1 種別 1 社」はページごとに適用する

ADR 0010 の原則は変えず、適用の単位を「1 ページ・1 枠・1 種別につき 1 社」と読み替える。

- 原則の目的は 1 画面での選択の負荷とクリックの分散を避けることなので、県ごとに違う会社が
  出ても目的は保たれる
- サイト全体で 1 種別 1 社に固定すると、地域限定の案件を 1 件も使えず、この ADR の意味が無くなる
- `ad_check.py` の検査も「ページごとに 1 種別 1 リンク」に読み替える。サイト全体では数えない

### 5. 計測は当面 枠の単位のまま

転送ページ `/go/<offer>/<placement>/` は枠ごとに 1 枚（ADR 0010）。県別の内訳は取れない。
`/go/<offer>/<placement>/<pref>/` にすれば取れるが、転送ページが最大 47 倍に増える。
まず枠の単位で始め、県別の内訳が要ると分かってからパスを増やす。

## 着手条件

- sitemill 側で地域限定の案件が保留に回るようになっていること（sitemill ADR 0021）
- **地域限定の案件が実際に 1 件以上あること**。いまは 0 件。案件が無いうちに枠だけ作らない
- その県に、地域限定の案件か県独自の補助制度があること。中身の無いページを 47 枚作らない

## 影響

- sitemill 側の変更は要らない。対応地域は akiya の `affiliates.py` が持つ
- 掲載 URL の届け出が最大 47 行増える
- `/owners/` は全国対応の案件だけのまま変わらない
- 市町村ページ・物件ページ・トップは今までどおり広告を置かない

## 却下した案

- **市町村ページに直接置く**: 掲載 URL を 1,740 件は届け出られない。読み手の多くが購入検討者で、
  ADR 0010 の判断に反する。検査の対象も 1,740 ページに増える
- **`/owners/` を読み手の位置で出し分ける**: 静的サイトなので中身は配置のときに決まる。
  JavaScript で差し替えると、広告表記が最初の広告リンクより前にあることの検査（ADR 0010）が
  成り立たなくなる
- **地域限定の案件を全国の枠に混ぜる**: 対象外の県の所有者に、その県では申し込めない相談先を
  見せることになる
- **市町村ごとの所有者向けページ**: 1,740 ページのほとんどが同じ内容になり、薄いページを量産する

## 追記: 実装した（2026-09-14）

着手条件の「地域限定の案件が 1 件以上ある」は、もしもの検索結果に札幌限定・釧路限定の案件が
実在することを確認して満たしたと読んだ。申請を実装待ちに、実装を案件待ちにすると互いに止まる。
先に受け皿を作れば、承認されてから掲載まで広告主を待たせない。

入れたもの。

- `Offer` に `regions`（都道府県名）と `region_quote`（対応エリアの原文）
- 枠 `owners-pref-consult`（`/owners/{pref}/` の「相談先」）。`Placement.page_path` に `{pref}` を
  含む枠は都道府県ごとに展開する
- `offers_for(枠, pref=県名)` が、その県の案件 → 全国対応 → 出さない、の順に選ぶ。
  同じ段では点数（`order`）で決める
- `/owners/<pref>/` のページ。県内の補助制度・空き家バンクの窓口・掲載件数を出す。
  **県内の補助制度か、その県の広告案件があるときだけ作る**（いまは長野県の 1 枚だけ）
- 市町村ページと物件ページの所有者向け導線は、その県のページがあればそちらへ向ける
- `ad_check` は `{pref}` を含む枠を生成物から展開して検査する。地域限定の案件はその県のページに
  だけ出るので「どれか 1 ページに出ていること」を見る

変えなかったもの。転送ページは枠の単位のままで、県別のクリック数は取らない（本文の 5）。
