# ADR 0013: 「巡回してよいか」と「物件一覧が取れるか」を分ける

- ステータス: 採用（2026-09-14）
- 関連: ADR 0012 の追記（補助制度の収集）、sitemill ADR 0011（発見と確信度）・0015（適応間隔）・0017（巡回の二段ゲート）

## 背景

補助制度の収集は 263 自治体（全 1,741 の 15%）にしか届かない。巡回するページ（`pages`）は
`policy: crawl` の source にしか付かず、その `policy` は**物件一覧が取れるかどうか**で決まっていた。

残る 1,478 自治体が link_only なのは、バンクのページの形の問題である。

| 内訳 | 件数 |
|---|---|
| バンクのページが見つからない | 895 |
| 制度案内だけ（物件一覧が無い） | 539 |
| JavaScript 描画で取れない | 38 |
| 民間プラットフォームに載っている | 6 |

どれも**公式サイト自体は自治体のドメイン**で、補助金のページはそこにある。実際、1,478 件すべてに
運営主体の根拠（引用と URL）と公式 URL が揃っている。巡回してよい相手であることは確認済みで、
取れないのは物件一覧だけである。

## 決定

### 1. `policy` と `bank_status` の連動を切る

2 つの問いを別の項目で持つ。

| 項目 | 意味 |
|---|---|
| `policy` | **巡回してよいか**。運営主体が確認できていて、巡回するページがあるか |
| `bank_status` | **物件一覧が取れるか**（available / third_party_only / spa_unsupported / info / none） |

`policy: crawl` の意味を「物件一覧を巡回する」から「巡回するページがある」に変える。物件一覧が
無くても補助金のページがあれば `crawl` になり、`pages` には補助金のページだけが入る。

**不変条件: `policy == crawl` であることと、`pages` が空でないことは一致する。**

### 2. 新しい `policy` の状態は足さない

`subsidy_only` のような状態を足すと、`pending` を含めて 4 状態になり組み合わせが増える。
「link_only だが補助金は巡回する」のような中間を表現できず、結局もう 1 つ軸が要る。
自治体ごとに 2 つ目の source を作る案も採らない。source が最大 3,400 件になり、
「1 市町村 = 1 source」を前提にしている箇所（`muni_by_source`・件数の集計・一次情報リンク）が崩れる。

### 3. `heal` の対象は `bank_status == "available"` で絞る

自己修復は「巡回しているのに物件が 0 件」の source を直す処理で、いまは `policy == "crawl"` で
判断している。決定 1 のあとにそのままにすると、**物件一覧を取るつもりのない 1,478 自治体が
毎晩の自己修復に流れ込む**。物件一覧が取れる source だけを対象にする。

### 4. 巡回の間隔は既存の適応間隔に任せる

補助金のページは年度替わりと募集開始のときしか変わらない。sitemill ADR 0015 の規則で、
28 日変化が無ければ週 1 回まで落ちる。初日から週 1 に固定するには種別ごとの間隔が要り、
それは engine の変更になる。効果に見合わないので入れない。

### 5. 探索は公式トップとバンクのページの両方から

補助金のページは、バンクのページから 1 段で届くとは限らない。「住まい」「くらし」のような分類
ページを 1 段挟む（高知県の実測で 2/12 → 8/12）。バンクが民間プラットフォームにある自治体では、
起点を公式 URL にする。robots.txt はこれまでどおり取得のたびにホスト単位で守る。

## 影響

- 巡回対象の source が 263 から最大 1,741 に増える。ただし `pages` に入るのは補助金のページだけで、
  物件一覧を新たに巡回するわけではない
- 画面の「巡回中の市町村」は `bank_status` を見ているので数字は変わらない
- 夜間の取得が増える。適応間隔で週 1 に落ちたあとで 1 晩あたり 600 ページ前後
- 初回の一括取得は Actions の無料枠を使わず手元で回す（`docs/runbook/subsidies.md`）
- 運営主体を判定できていない `pending` は対象外のまま

## 着手条件

link_only が多い県を 1 つ選んで取得率と費用を実測し、全国の見積もりを更新してから全国に広げる。
高知県の 67% は巡回中の自治体での数字で、バンクが見つかっていない自治体では公式トップからの
探索になるため、数字が変わる。
