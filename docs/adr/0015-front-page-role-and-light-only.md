# ADR 0015: トップページの役割と、ライト固定

- ステータス: 採用（2026-09-15）
- 関連: ADR 0002（方向性の配色）、ADR 0014（一覧の密度とページの重さ）

## トップページは入口であって、物件を探す画面ではない

「空き家バンク」で検索して着地した人が、最初の 1 画面で分かるべきことは 4 つ。

1. **ここは何か** — 全国の自治体が運営する空き家バンクを横断して見られる場所
2. **ここは何ではないか** — 民間の仲介サイトではない。申込みは自治体の窓口で受け付けている
3. **自分に関係があるか** — 自分の県・町の物件や制度があるか
4. **次にどこへ行くか**

### 過剰だったもの

- **数字 6 つ**。価格の中央値・無償譲渡・最終更新は「探す」段階の情報で、着地した人の理解には要らない
- **絞り込み 8 項目の検索フォーム**。物件を探す画面の機能で、入口の役割とは別
- **都道府県カード 47 枚**。入口としては妥当だが場所を取る

### 足りなかったもの

- **所有者への入口**。検索から来る人には所有者も一定数いるのに、導線が最下部の CTA だけだった
- **カバー範囲の正直な提示**。全 1,741 市町村のうち物件を見られるのは 246。期待と実態のずれは先に埋める
- **信頼の根拠**。毎日巡回・一次情報リンク・推定値を混ぜない、がフッターまで行かないと分からなかった

### 決めたこと

第 1 画面は「見出し → 1 文のリード（仲介しないことを含む）→ 数字 2 つ → 入口 3 つ」。
入口は「都道府県から探す」「補助制度を調べる」「空き家をお持ちの方へ」。
補助制度の件数は、それを見に行く入口の説明文に置く（数字だけを並べない）。

第 2 画面以降は、都道府県のチップ（掲載のある県を件数つきで先に）、畳んだ検索フォーム、
最近確認した物件（横スクロールなのでカードのまま。ADR 0014）、「このサイトの作り方」。

375×812 で、入口 3 つまでが第 1 画面に収まることを実測して確認する。

### 分かったこと

ヘッダー（ロゴ＋ナビ 4 項目）が 375px で 2 段に折り返し、**169px** を占める。第 1 画面の 21%。
今回は触っていないが、第 1 画面をこれ以上詰めるならここが最大の余地。

## ライト固定にする

`prefers-color-scheme` と `data-theme` の分岐を全廃し、`color-scheme: light` にする。

- 生成り×深緑×柿渋は**ライトを前提に設計した配色**で、ダークは同じ色相で組み直した派生だった。
  2 つの見た目を維持する手間に対して得られるものが少ない
- 利用者層（40〜60 代の空き家所有者）を考えると、ダークでの閲覧は多数派ではない

コントラストの基準（本文 7:1、大きな数字 4.5:1、UI 部品 3:1）は変えない。ライトのトークンを
一切触っていないので、実測値も設計時のまま（本文 14.96 / 16.57、他は 4.85〜13.10）。

### sitemill の図解はライト固定にできない

`chart_css()` がダーク分岐（`:root:not([data-theme="light"])` と `:root[data-theme="dark"]`）を
出力する。sitemill は別セッションの担当なので触らない。`<html>` に `data-theme="light"` を付けると
両方の選択子が当たらなくなるので、それで無効化した。ダーク用の宣言は HTML に残るが効かない。

sitemill 側に「ライト固定のサイトではダーク分岐を出さない選択肢」を提案として出す
（`docs/design/04-sitemill-proposals.md`）。
