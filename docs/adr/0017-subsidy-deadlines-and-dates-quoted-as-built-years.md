# ADR 0017: 補助制度の締切は「終わり」と書いてある日付だけ。日付から切り出した年を築年にしない

- ステータス: 採用（2026-09-17）
- 関連: ADR 0004（quote-then-parse）、sitemill v0.7.2（和暦の年と曜日の読み取り）、
  `docs/design/04-sitemill-proposals.md` の H・I

## 背景

sitemill v0.7.2 で、期間の読み取りが「令和7年」を今年として扱っていた誤りが直った。akiya-atlas で
同じ誤りが出ていないかを調べた。

- **和暦の誤りは無かった。** akiya-atlas は `parse_date_range` を使っておらず、締切も築年も
  年の書かれた日付しか読まない。保存済みの締切 647 件で、原文に書かれていない年を使ったものは 0 件
- **代わりに、日付の読み取りの別の誤りが 2 つ本番に出ていた**（下の失敗の経緯）

## 失敗の経緯

### 1. 受付中の補助制度に「募集終了」と出ていた（253 件中 166 件）

締切は「募集期間の引用の中で、年の書かれた日付の最も遅いもの」だった。

- 「令和8年4月13日(月曜日)から10月30日(金曜日)」は、終わりの日に年が無いので読まれず、始まりの
  **4 月 13 日が締切**になった。館林市の耐震補助（10/30 まで受付）、伊勢崎市の空き家補助 3 件などに
  「募集終了」が付いていた
- 「令和8年4月1日から受付開始」「令和7年4月1日以降の取得に限ります」も、始まりの日が締切になった

「募集終了」は利用者が申請を諦める印で、補助制度はこのサイトの差別化の核にあたる。
**なぜ見えなかったか**: 締切のテストは「令和8年4月1日から令和9年3月31日まで」のように両端に年がある
例だけで、実データの書き方（終わりの年の省略、始まりだけ）を当てていなかった。

### 2. 三原市の 80 件で、掲載日を築年として出していた

一覧の見出しの無い列に掲載日「令和８年 ６月29日」が並び、LLM が「令和８年」を築年の引用に選んだ。
引用は本文に実在するので照合を通り、パーサは引用しか見ないので「2026年築」になった。
**プロンプトで禁じても（2 通りの書き方で試した）答えは変わらなかった。**

## 決定

### 締切（`akiya_atlas/deadline.py`）

- 締切にするのは**終わりだと書いてある日付だけ**: 「まで」「必着」「で終了」が続く、「期限:」が前に付く、
  「から」「~」の直後にある（期間の終わり）
- 「から」「より」「以降」「受付開始」が続く日付は始まりの日。**印の無い日付**（「令和8年7月10日(金曜日) 午前9時」）
  は始まりか締切か分からないので締切にしない
- 年の無い日付は、期間の終わりのときだけ始まりの年（元号）を引き継ぐ。今年で補わない
- 曜日が年と食い違う、締切より後に始まる期間がある、延長・随時募集への切り替えが書いてある、のどれかなら
  締切にしない

画面では「受付中」と「不明」は同じ見た目で、違いは「募集終了」の印だけ。**締切を絞る方向の誤りは
印が出ないだけ、広げる方向の誤りは申請を諦めさせる**ので、迷う書き方は締切にしない側に倒す。

保存済みのデータは `akiya-atlas subsidy-deadlines [--apply]` で引用から読み直す（LLM は呼ばない）。
締切が空だった行は、引用が抽出時の本文（生 HTML のキャッシュ）に実在するときだけ値にする
（2026-09-17: 79 件中 24 件。49 件は LLM がつなぎ合わせた引用で本文と一致せず、6 件はキャッシュが無い）。

### 過年度の可能性

締切を読めず、年度の原文が今年度より前の年度だけ（「令和7年度」「令和4年度~令和6年度」）なら
「過年度の可能性」と出す。**終わったとは言わない**（年度の見出しを更新していないだけの続く制度が多い）。
「令和7年度から」のように始まりだけの年度と、締切を読める制度には出さない。2026-09-17 時点で 39 件。

### 築年

取り込み（`service.ingest`）で本文を読み直し、築年の引用が**月日付きの日付の一部として現れ、どこにも
築年の見出し（築・建築・建設・竣工・建物）が付いていない**なら値にしない（`listing_date_not_built_year`）。
統合では、以前の parsed の値より優先する（残すと直らない）。三原市の 80 件が外れ、他の 866 件は 0 件。

## 影響

- 「募集終了」253 件 → 87 件（手で全件を見て、すべて実際に終わった期間）＋締切が新たに読めた 3 件
- エンジン側に置きたいもの 2 点を `docs/design/04-sitemill-proposals.md` に書いた（H: `parse_year` が
  「築49年(2026年時点)」を 2026 年と読む。I: 引用の前後の本文を見て値を捨てるフック）
