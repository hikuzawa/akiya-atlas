# 01. 現状の問題点（2026-09-11、https://akiya-atlas.com）

モバイル幅（375px）とデスクトップ幅（1440px）で主要 5 ページを表示し、テンプレート（`templates/`）と
スタイル（`static/style.css`、16px 基準・system-ui・青リンク #2a78d6）を照合した。

## 全体
1. **文書レイアウトのまま**: 見出し（左に青い縦線）・段落・罫線表の繰り返し。ロゴ・図形・色面などのブランド要素が無く、
   リンク色はブラウザ既定に近い青。どのページも同じ骨格で、汎用テンプレートか機械生成に見える。
2. **数字が主役になっていない**: トップの「3 都道府県 / 135 市町村 / 187 掲載物件」は 1 行の小さな帯。市町村ページの
   「70 掲載中 / 62 売買 / 9 賃貸」も同じ。価格の中央値・最安、築年の分布、補助金の有無は上部に無く、表の中に埋もれる。
3. **表が中心で、スマホで読めない**: 都道府県ページは 77 行 × 8 列、市町村ページの物件一覧は 8 列。スマホでは横スクロールになり、
   最初の画面に「なし／登録制／0／0／—」が並ぶ（長野県は 77 市町村のうち巡回して物件があるのは 14）。物件がある市町村が埋もれる。
4. **文字が小さい**: 本文 16px、補助テキスト 14px（.88rem）、表 14.9px、行間 1.7。年配の利用者には小さく、コントラストは
   十分でも視認性が低い。ナビゲーションはテキスト 4 本で、スマホでは 2 行に折り返す。
5. **一次情報への導線が弱い**: 「公式ページ」はテキストリンク。外部に出ることが分からず、ボタンなのは物件ページの 1 か所だけ。
6. **信頼シグナルの置き場所**: 「この情報について」はフッター直前にあるが、ページ上部では最終更新・一次情報リンクが控えめ。
   物件ページの取得日時・抽出方法は末尾の小さな 1 行。
7. **図解の設計**: 市町村別件数の横棒は 77 本で長大。価格・築年のヒストグラムは件数がそろった市町村にしか出ず、色は汎用の青。
8. **ダークモード**: OS 設定に追従するが配色が無個性（黒背景 + 青リンク）。

## ページ別
### トップ
- ヒーロー無し。H1 の直後に検索フォーム（セレクト 5 個）と、先頭 100 件のリンク列が続き「情報の海」になる。
- 都道府県カードは県名と件数だけ。市町村別件数の横棒は 135 本。
- 所有者向け導線は最下部の CTA ボックス 1 つ。

### 都道府県（/nagano/）
- 上部に数字が無い（件数の合計・巡回市町村数・補助金あり市町村数）。
- 77 行の表が主役。地図が無いので「どこに物件があるか」が分からない。
- 「登録制／民間のみ／JS 未対応／なし」の状態タグが小さく、意味の説明が無い。

### 市町村（/nagano/202193-tomi/）
- 「運営: 東御市（公式）」の根拠と公式ページへの主導線が本文中のテキストリンク。
- 補助制度が箇条書きで、種類（移住・改修・解体）が小さなタグ。
- 物件一覧が表。価格・所在地・築年・延床は列に散り、バッジ（値下げ・掲載終了の可能性）は見出しリンクの後ろ。
- 位置の地図は API キー未設定時に外部リンク 1 行。

### 物件（/nagano/202193-tomi/122/）
- H1 が「東深井の便利な土地」で、価格（350 万円）は本文の中。
- 「記載なし」が 6 項目縦に並び、スマホで 2 画面分。要約が短いと間延びする。
- 主ボタン（自治体の物件ページ）は良いが、外部に出ることを示すアイコンが無い。

### 所有者向け（/owners/）
- フロー図（sitemill.charts の flow_diagram）は箱 130px・文字 11px 程度で小さい。
- 「相続した空き家の選択肢」の全体像（住む／貸す／売る／登録／解体／管理）が無く、いきなり「売却・賃貸までの流れ」から始まる。
- 相談先カードは「準備中」の灰色文字で行き止まりに見える。補助制度の表は 5 列でスマホで横スクロール。

## 残すもの（良い点）
- 構造化: `section` + `aria-labelledby`、パンくず、スキップリンク、`lang="ja"`。
- 透明性: 要約が自動生成であることの明記、原文引用、坪換算の注記、取得日時・抽出モデル、成約済／掲載終了の可能性の表示。
- 信頼ブロック（`data-sitemill-trust`）、免責、運営者情報、robots.txt / sitemap / 404 / canonical / OGP / JSON-LD。
- 地図の埋め込みはキー未設定時に外部リンクへフォールバック（`sm-embed-fallback`）。
- 検索は静的 JSON 索引をクライアントで絞り込むだけ（JS は 1 ファイル）。

## 計測（before）
- スクリーンショット: `scratchpad/design/before/{top,prefecture,municipality,listing,owners}-{mobile,desktop}.png`（リポジトリには入れない。after と並べて報告する）
- Lighthouse は実装後に before/after を同条件（モバイル・シミュレート）で計測する。
