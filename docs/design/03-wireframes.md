# 03. ワイヤーフレーム（主要 5 ページ）

モバイル（375px）を基準に描く。デスクトップ（≥ 60rem）は同じブロックを 2〜3 列に並べるだけで、順序は変えない。
「データ源」は今のテンプレートが受け取る変数（`src/akiya_atlas/pages.py` の context）。テンプレート内で計算できないものは
`04-sitemill-proposals.md` に提案し、それまでは代替表示にする。

## 共通
```
┌──────────────────────────────────────────┐
│ [ロゴ] 空き家アトラス      物件を探す │ 所有者の方へ │ データ │  ← 深緑の帯、白字
├──────────────────────────────────────────┤
│ パンくず（16px、リンクは下線）                              │
│ H1                                                          │
│ ┌ 数字の帯 ────────────────────────────────────────────┐   │
│ │  187      14 / 135     300〜500万円が最多   補助金 9 市町村 │   │
│ │  掲載物件  巡回中の市町村  価格帯（ミニ分布）   （移住・改修・解体）│   │
│ └──────────────────────────────────────────────────────┘   │
│ [ 公式ページで詳細を見る ↗ ]  ← 一次情報がある page では主ボタン │
│ ... 本文ブロック（白い面のカード）...                        │
│ ┌ この情報について（信頼ブロック、sitemill マクロ）────────┐ │
│ │ 最終更新 2026年9月11日 05:46 │ データ件数 187 件           │ │
│ │ 一次情報: 東御市 空き家バンク（取得 …）… │ 運営者: … 連絡先 │ │
│ └──────────────────────────────────────────────────────┘   │
│ 免責 / © 空き家アトラス                                       │
└──────────────────────────────────────────┘
```

## 1. トップ（/）
```

lead 3 県 135 市町村の公式ページを毎日巡回し、要約と一次情報リンクだけを載せています。
┌ 数字の帯 ───────────────────────────────┐
│ 187 掲載物件 │ 3 都道府県 │ 135 市町村 │ 最終更新 9月11日 │
└─────────────────────────────────────────┘
┌ 都道府県から探す ─ 大きなカード × 3（PC は横並び）─┐
│ 長野県  176 件 ▮▮▮▮▮▮▮▮▮░░ 14/77 市町村が公開  補助金 9 │
│ 香川県    5 件 ▮░░░░░░░░░░  1/17            補助金 2 │
│ 沖縄県    6 件 ▮░░░░░░░░░░  1/41            補助金 1 │
└─────────────────────────────────────────┘
┌ 物件を探す（絞り込み）────────────────┐
│ [都道府県 ▾][市町村 ▾]                     │
│ [価格帯 ▾][種別 ▾] □ 補助金のある市町村   │
│ 187 件が該当                               │
│ ┌ 物件カード ┐┌ 物件カード ┐（先頭 20 件、「さらに表示」で 20 件ずつ）│
└─────────────────────────────────────────┘

┌ 空き家をお持ちの方へ ─ 選択肢の図解の縮小版 + [選択肢を見る]┐

```
- データ源: `stats`（prefectures / municipalities / listings）、`prefectures`（name, url, municipalities, count）、`recent`（listing_row）、`trust.updated_at`。
- 都道府県カードの「公開している市町村数」「補助金あり市町村数」は今の `prefectures` 行に無い → 04 の提案。それまでは「市町村数 / 件数」だけ。
- 検索結果はカード描画に変更（`search.js`）。索引の行には価格・築年・補助金フラグ・所在地があるのでカードに必要な項目はそろう。
- 135 本の横棒グラフは廃止（都道府県ページの地図とカードに役割を移す）。

- 非巡回の市町村: H1 の直下に `status_card`（4 状態の説明文 + 公式ページの主ボタン）→ 補助制度 → 民間サイト → 位置 → 所有者導線。
- データ源: `muni`、`muni_row`、`listings`（listing_row: no, title, deal, price(文字列), band, address, built_year(数値), floor_area(文字列), status, status_text, url, updated）、`subsidies`、`external`、`map`、`chart_price`、`chart_built`、`no_listings_reason`。
- 数字の帯の価格帯は `band` を集計（Jinja の `selectattr`）。築年の範囲・中央値は `built_year`（数値）から計算。中央値の価格は数値が無い → 04。
- 「詳細あり」は今のデータに印が無い → `has_detail` が入るまで「築年・面積あり」（数値がそろっている）を表示。

```
┌ 選択肢の図解（SVG 分岐図、自動生成の注記）──────────────────────┐
│            ┌ 住む・使う ─ 向いている: 通える距離／最初の一歩: 現地確認     │
│            ├ 貸す ─────── 賃貸の需要がある／空き家バンクに賃貸で登録     │

└────────────────────────────────────────────────────────────────┘

```
- データ源: `flow_sale`、`flow_demolition`、`offers`（label, kind, description, ready, path）、`subsidies`（muni, muni_url, kind, name, url, summary, amount_text, checked_on）。
- 「選択肢の図解」は固定内容なのでテンプレート側の SVG（コード生成）。医療・法律・税務の個別助言に踏み込まない文言にする。

## デスクトップ（≥ 60rem）での違い
- ヘッダーは 1 段。数字の帯は横 1 行。カードは 2〜3 列。地図は左 2/3、凡例と市町村カードの先頭を右 1/3。
- 物件ページは「事実の帯 + 主ボタン」を左、要約を右の 2 列にせず、1 列のまま最大幅 48rem に絞る（読み物として）。
