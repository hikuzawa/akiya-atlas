## フォントの撤退条件の判定
02 の条件（LCP が 0.5 秒以上悪化、または CLS が 0.1 超）に照らした結果:
1. **全文 BIZ UDPGothic（400/700、同期読み込み）**: 日本語フォントは unicode-range の細切れで配信されるため、1 ページで 800KB 前後のフォントを読み込み、LCP が 2.9 秒 → 7.9 秒に悪化（Perf 91 → 59）。不採用。
2. **見出しと数字だけ（700 のみ、非同期読み込み）**: フォント 130〜180KB、LCP はトップで +0.6 秒（3.48 秒）、市町村で +0.36 秒。トップが条件を超えた。
3. **システムフォントのみ（採用）**: LCP はトップ +0.33 秒、他は +0.1〜0.15 秒（HTML が大きくなった分）。CLS 0。Perf 90〜94。

結論: **Web フォントは使わない**。読みやすさは文字サイズ（本文 18〜19px、行間 1.85）とコントラストで担保する。
フォールバック順は iOS/macOS の Hiragino Sans、Windows の Meiryo（Yu Gothic UI より太く読みやすい）、Android の Noto Sans JP。
再挑戦するなら、自前でサブセット化（使用文字だけの woff2 を `static/` に置き `size-adjust` で fallback と幅を合わせる）が前提。

都道府県ページの A11y 96 はタイル図の 6〜10 件の段階（白字 on `#7FA99B`）のコントラスト不足だったので、文字色を墨に変えて修正した。

## 本番への反映の仕方
テンプレートや CSS だけの変更は、GitHub Actions → pipeline → Run workflow で **mode = deploy-only** を選ぶと、
巡回・抽出・heal・データのコミットを行わず、main の現在のデータで build → 検査 → deploy だけを行う（数分）。
日次の schedule と mode = full は従来どおり。
