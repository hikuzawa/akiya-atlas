# 案 B（白地・紺・橙）

2026-09-20 に採用。見本は `docs/design/akiya-muni-mobile.html`（390px）と
`akiya-muni-pc.html`（1280px）の 2 枚で、市町村ページのもの。他のページ種別は同じ部品と配色で揃える。

前の配色（生成り×深緑×柿渋、`02-direction.md`）から、白地・紺・橙に変えた。
本文 18px / 行間 1.85 と、Web フォントを使わない判断（`05`）はそのまま引き継ぐ。

### 見本から動かした 2 色

コントラストの基準（本文 7:1、大きな数字 4.5:1、UI 3:1）に届かなかったため。

- **アクセント `#C4562B` → `#A8441A`**: `#C4562B` は白との比が 4.46:1 で、白い数字を載せる
  タイルが 4.5 に届かない。`#A8441A` は 5.99:1
- **補助文 `#5B6577` → `#464F61`**: `#5B6577` は白地 5.88:1・灰面 5.29:1 で本文の 7:1 に届かない。
  `#464F61` は白地 8.23:1・灰面 7.41:1・淡橙面 7.60:1

見本の `#E07A2F` は白文字で 3.00:1 しか出ないので、文字とボタンの背景には使わない。
装飾（細い帯・ピン）だけに回した。

## 骨格

- **ヘッダー**: 白地。紺の小さなロゴ枠とサイト名。公的機関に見えないよう、紺は面ではなく
  ロゴ枠だけに使う。信頼ブロックの運営者は「空き家アトラス 運営（民間）」
- **ヒーロー帯**: 紺の面にパンくず・県名 ・ ローマ字・見出し・最終確認。全幅
- **数字タイル**: 3 つ。スマホでは帯に重ね、1024px 以上は帯の下に置く（重ねると固定サブナビに乗る）
- **4 つの入口**（一覧・地図・補助金・相談）: スマホは画面下に固定、1024px 以上はヒーロー直下の
  固定サブナビ。同じ markup を CSS で切り替える
- **2 カラム**（1024px 以上）: 左が本文、右 360px が地図・窓口・所有者向け。地図が貼り付く。
  スマホでは「地図 → 本文 → 窓口・所有者向け」の 1 列
- 角丸 12px（大きなカードは 14px）、影 `0 2px 10px rgba(20,33,61,.10)`、太さは 700 と 800

## 見本と変えたところ

1. **1024px 以上では数字タイルを帯に重ねない**。帯の直下に 4 つの入口が入るため
2. **ヘッダーに検索ボタンを置かない**。「物件を探す」が同じ `/#search` を指していて二重になる
3. **地図はリンク表示のまま**。`GOOGLE_MAPS_EMBED_KEY` が未登録（`docs/human-tasks.md`）
4. **本文 18px / 行間 1.85 を維持**（見本は 17px）。年配の利用者向けの判断（`02-direction.md`）
5. 見本にある物件の写真枠は作らない。持っていないデータを持っているように見せない
6. 物件は ADR 0014 の 1 行表示から、左に価格の面を持つカードに変えた。1 件あたり 98px で、
   1 行表示より 30px ほど高い。価格が面になるぶん一覧で追いやすいので、高さの増加を受け入れる

## lastmod の扱い

指紋はテンプレートが描いた HTML から作るので、テンプレートを変えると全ページの指紋が変わる。
sitemill v0.7.4 は台帳の `layout` キーで「見た目を変えた回」を見分け、指紋を作り直して日付を
据え置く（`build.lastmod_relearned`）。**キーがまだ無い台帳は、その回は刻むだけで作り直さない**ので、
案 B を載せるコミットでは、変更前のテンプレートの `layout` キーを台帳に書いてから載せた。
手順は `docs/runbook/operations.md` 3-6。
