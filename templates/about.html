{{ ui.section_head("policy-title", "掲載方針") }}
  • 掲載するのは、自治体または自治体の移住推進組織が運営主体と明記された空き家バンクの情報だけです。民間プラットフォームはリンクのみ掲載します。
  • 物件の写真と詳細本文は掲載しません。要約と、価格・面積などの数値、一次情報（自治体ページ）へのリンクにとどめます。
  • 数値は自治体ページの原文から機械的に抽出し、推定や換算は行いません（坪から㎡への換算のみ、その旨を明記して表示します）。
  • すべての情報に一次情報の URL と取得日時を付けています。
  • 図解はデータから自動生成した SVG で、写真ではありません。地図は Google Maps の埋め込み機能を使っています。都道府県ページの市町村の升目図は地理データを使わず、市町村コード順に並べたものです。

{{ ui.section_head("disclaimer-title", "免責") }}

掲載内容の正確性には努めていますが、自治体ページの更新や抽出の誤りにより実際と異なる場合があります。物件の申込みや契約は、必ず自治体および関係者に直接ご確認ください。本サイトは物件の仲介を行いません。

{{ ui.section_head("privacy-title", "プライバシーポリシー", "お預かりする情報と、外部サービスの利用について") }}

お問い合わせフォームに入力された内容（お名前、メールアドレス、種別、お問い合わせ内容、送信日時）は、Google フォームを通じて運営者の Google スプレッドシートに保存し、お問い合わせへの対応と、対応の記録のために利用します。

自動返信の文面の作成とお問い合わせ内容の分類には AI（Anthropic 社の Claude）を使用しており、お問い合わせ内容は Anthropic 社の API に送信されます。自動返信にはその旨を明記しています。

掲載内容の訂正・削除のご依頼など、運営者の対応が必要なものは、対応の記録として、お問い合わせ内容の一部（対象の URL と本文）を運営者の非公開の作業管理ツール（GitHub Issue）に転記します。お名前とメールアドレスは転記しません。

お預かりした情報は対応の完了後も記録として一定期間保管し、法令に基づく場合を除いて第三者には提供しません。削除をご希望の場合は、同じフォームからお知らせください。
